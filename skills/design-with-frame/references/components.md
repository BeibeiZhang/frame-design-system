## Install and inspect exact props

In a configured React shadcn project, install a published slug with `npx shadcn@latest add @frame/<slug>`, for example `npx shadcn@latest add @frame/chat-message`. Import the installed frame.css once and wrap Frame content in `frame-root`. The namespace registry is https://system.beibeidesign.com/r/{name}.json.
